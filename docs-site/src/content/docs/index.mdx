Ritual is a free, open-source command-line program. It works on a folder of markdown files, one per deck, collection or wanted list, and everything it does reads or writes those files.

<CardGrid>
  <Card title="Lists are markdown files" icon="seti:markdown">
    Each list is one file under `decks/`, `collections/` or `wanted/`. Edit it with Ritual or by
    hand, and keep the folder in git. The changes Ritual makes are logged in a `.changes.md` file
    beside the list.
  </Card>
  <Card title="Prices from four stores" icon="star">
    TCGplayer prices by default; Cardmarket, Card Kingdom and Cardhoarder (MTGO tix) when you enable
    them with `priceSources`. `ritual sell` shows what Card Kingdom's buylist would pay you.
  </Card>
  <Card title="Import and sync" icon="random">
    Import decks from Archidekt, Moxfield and MTGGoldfish, and lists from text and CSV files. Sync
    decks and your collection both ways with Archidekt.
  </Card>
  <Card title="A website you host anywhere" icon="seti:html">
    `ritual build-site` writes your lists as a static website: browse, filter, price, and plan
    trades. `ritual init-site` sets up publishing to GitHub Pages.
  </Card>
  <Card title="Terminal or browser" icon="pencil">
    `ritual edit` is an interactive editor in the terminal. `ritual admin` runs the same editing in
    a browser, along with imports, syncs and site builds.
  </Card>
  <Card title="Works with AI assistants" icon="puzzle">
    An MCP server gives assistants tools to read and edit your lists. Installable skills teach a
    coding agent to run the `ritual` command itself.
  </Card>
</CardGrid>

Card data comes from [Scryfall](https://scryfall.com) and is kept in a local cache, so after the first download most commands work offline.

## From Nothing to a Website

```bash
curl -fsSL https://raw.githubusercontent.com/sloshy/ritual/main/scripts/install.sh | bash
mkdir my-cards && cd my-cards
ritual import https://archidekt.com/decks/12345
ritual serve --build    # open http://localhost:3000
```

Windows, prerelease and source builds are on the [install page](/start/install/). The [quick tour](/start/tour/) goes on from here: pricing, editing, syncing and publishing.
