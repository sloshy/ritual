Ritual is a command-line toolkit for Magic: The Gathering. It keeps your decks, collections, and wanted lists as plain markdown files, prices them, imports from and syncs with the sites you already use, and publishes them as a website you can host anywhere.

## Installation

<Tabs>
  <TabItem label="macOS / Linux">

```bash
curl -fsSL https://raw.githubusercontent.com/sloshy/ritual/main/scripts/install.sh | bash
```

  </TabItem>
  <TabItem label="Windows (PowerShell)">

```powershell
irm https://raw.githubusercontent.com/sloshy/ritual/main/scripts/install.ps1 | iex
```

  </TabItem>
</Tabs>

The installer puts the `ritual` binary on your `PATH`. Run `ritual --help` to check it worked.

### Prerelease Builds

Ritual is pre-release, so there is no stable release yet. To install the newest build, prereleases included:

<Tabs>
  <TabItem label="macOS / Linux">

```bash
curl -fsSL https://raw.githubusercontent.com/sloshy/ritual/main/scripts/install.sh | bash -s -- --prerelease
```

  </TabItem>
  <TabItem label="Windows (PowerShell)">

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/sloshy/ritual/main/scripts/install.ps1))) -Prerelease
```

  </TabItem>
</Tabs>

Both installers accept these options:

| Option                             | Environment variable       | Description                                                                 |
| ---------------------------------- | -------------------------- | --------------------------------------------------------------------------- |
| `--prerelease`/`-Prerelease`       | `RITUAL_PRERELEASE=1`      | Install the newest release, including prereleases.                          |
| `--version <tag>`/`-Version <tag>` | `RITUAL_VERSION=<tag>`     | Install a specific release tag. Use `prerelease` for the newest prerelease. |
| —                                  | `RITUAL_INSTALL_DIR=<dir>` | Where to install the binary.                                                |

### Other Methods

You can also download a binary for your platform from the [releases page](https://github.com/sloshy/ritual/releases) and run it directly:

```bash
./ritual --help
```

### Building from Source

Ritual runs on [Bun](https://bun.sh). Install the dependencies, then build the binary:

```bash
bun install
bun run build
```

## Your First Deck

Ritual works in the directory you run it from. Make a folder for your cards, step into it, and create a deck:

```bash
ritual new deck "My Commander Deck"
ritual add-card "My Commander Deck" Sol Ring
```

The first command that needs card data offers to download Scryfall's card database into a local cache. Say yes. Every later lookup reads from that cache, so it is fast and works offline.

Already have a deck online? Import it from Archidekt, Moxfield, or MTGGoldfish instead:

```bash
ritual import https://archidekt.com/decks/12345
```

From here:

```bash
ritual edit                       # open the interactive editor
ritual price "My Commander Deck"  # what the deck costs today
ritual serve --build              # build the website and serve it at http://localhost:3000
```

## What You Get

- **Lists as files.** Each deck, collection, and wanted list is one markdown file under `decks/`, `collections/`, or `wanted/`. Edit them with Ritual or by hand. See [List Files](/list-format/).
- **Three ways to work.** The command line, a browser-based [admin site](/admin/) you run with `ritual admin`, and a [public site](/public-site/) you build and host.
- **Imports and syncs.** Decks from Archidekt, Moxfield, MTGGoldfish, plain text, and CSV files, plus two-way sync with Archidekt for decks and your collection.
- **Prices.** TCGplayer, Cardmarket, and Card Kingdom prices for every list, and Card Kingdom buylist quotes when you want to sell.
- **Card lookup.** Search Scryfall with its full query syntax from the terminal.
- **AI agents.** An [MCP server](/commands/mcp/) and installable [agent skills](/commands/skills/) so an assistant can drive Ritual for you.
